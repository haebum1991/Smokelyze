NOAA/GOES Satellite Retrieval

Retrieves and processes geostationary satellite data from NOAA's GOES series (GOES-East and GOES-West) over North America. This includes high-resolution Aerosol Optical Depth (AOD) from the Advanced Baseline Imager (ABI) Level 2 products as well as true-color GeoColor imagery, providing continuous daytime monitoring of wildfire smoke plumes and aerosol transport.

1. Key Information

  • Purpose: Track overhead aerosol optical depth (AOD) and true-color satellite imagery for near real-time smoke plume identification and transport monitoring.
  • Source: NOAA GOES Public Datasets on Google Cloud Storage (GCS) and NOAA NESDIS OGC Imagery API.
  • Products: ABI-L2-AODC-east / ABI-L2-AODC-west (Aerosol Optical Depth) and GOESEastCONUSGeoColor / GOESWestCONUSGeoColor (True-color imagery).
  • Satellite Continuity:
    • GOES-East: GOES-16 (before 2025-01-01) → GOES-19 (on or after 2025-01-01).
    • GOES-West: GOES-17 (before 2023-01-01) → GOES-18 (on or after 2023-01-01).
  • Refresh Rate: Sub-hourly to hourly observations across the Continental United States (CONUS) domain.

2. Main Workflow

1Cloud Query: Queries public GCS buckets (or NESDIS OGC API) for ABI L2 AOD or GeoColor imagery granules based on date and satellite domain.
2Quality Masking (AOD): Applies official Data Quality Flags (DQF == 0) and filters physically valid optical depth values (-0.05 ≤ AOD ≤ 5.0).
3Spatial Aggregation: Spatially aggregates raw 2 km resolution pixels by a factor of 2 (downsampling to ~4 km resolution) using mean bilinear sampling for web optimization.
4Projection Alignment: Reprojects native Geostationary (GEOS) projection into EPSG:3857 (Web Mercator) and crops raster to North American domain boundaries.
5Raster Web Encoding: Encodes normalized floating-point rasters into 8-bit unsigned integer PNG or compressed WebP tiles, exporting accompanying JSON metadata for exact frontend value reconstruction.

4. Technical Implementation

- Dynamic Satellite Bucket Routing

Routes queries dynamically to GOES-16/19 (East) or GOES-17/18 (West) GCS public storage buckets based on observation dates.

# Satellite routing logic based on transition dates
if (str_detect(product, "east")) {
  bucket <- ifelse(as.Date(date) < as.Date("2025-01-01"),
                   "gcp-public-data-goes-16",  # GOES-16 before 2025
                   "gcp-public-data-goes-19") # GOES-19 from 2025
} else if (str_detect(product, "west")) {
  bucket <- ifelse(as.Date(date) < as.Date("2023-01-01"),
                   "gcp-public-data-goes-17",  # GOES-17 before 2023
                   "gcp-public-data-goes-18") # GOES-18 from 2023
}

- AOD Quality Control & Filtering

Extracts raw ABI AOD fields alongside the Data Quality Flag (DQF) layer, enforcing strict quality masking before spatial aggregation.

# Load AOD and DQF subdatasets
i_rast <- terra::rast(valid_file, "AOD")
i_rast_dqf <- terra::rast(valid_file, "DQF")

# Apply Quality Mask: DQF == 0 & valid AOD range (-0.05 to 5.0)
i_rast_valid <- (i_rast_dqf == 0) & (i_rast >= -0.05) & (i_rast <= 5.0)
i_rast <- terra::mask(i_rast, i_rast_valid, maskvalues = FALSE, updatevalue = NA)

# Spatial Aggregation (2 km -> ~4 km)
i_rast <- terra::aggregate(i_rast, fact = 2, fun = "mean", na.rm = TRUE)

- Reprojection & 8-Bit Web PNG/JSON Export

Reprojects the aggregated raster to Web Mercator (EPSG:3857), normalizes values to an 8-bit range (0-255), and exports PNG tiles with JSON metadata for client-side value recovery.

# Reproject to EPSG:3857 (Web Mercator)
i_rast <- terra::project(i_rast, "EPSG:3857", method = "bilinear")
i_rast <- terra::crop(i_rast, terra::ext(crop_extent_3857))

# 8-bit Normalization
i_min <- terra::global(i_rast, fun = "min", na.rm = TRUE)[1, 1]
i_max <- terra::global(i_rast, fun = "max", na.rm = TRUE)[1, 1]

r_encoded <- (i_rast - i_min) / (i_max - i_min) * 255
r_encoded[is.na(r_encoded)] <- 0

# Save 8-bit PNG and metadata JSON
terra::writeRaster(r_encoded, filename = png_path, datatype = "INT1U", filetype = "PNG", NAflag = 0)
write(jsonlite::toJSON(list(min_val = i_min, max_val = i_max, crs_file = "EPSG:3857"), auto_unbox = TRUE), json_path)
