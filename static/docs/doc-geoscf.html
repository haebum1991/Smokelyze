NASA GEOS-CF Model Retrieval

Last Updated: 2026-08-24

Retrieves high-resolution surface atmospheric composition fields from NASA's GEOS-CF (Goddard Earth Observing System Composition Forecast) system. GEOS-CF provides real-time, global 1-hour analyses and forecasts of atmospheric chemistry at ~28 km resolution (0.25° × 0.25°), covering surface ozone (O3), nitrogen dioxide (NO2), particulate matter (PM2.5), carbon monoxide (CO), and other trace gas species.

1. Key Information

  • Purpose: Ingest high-resolution global atmospheric chemistry model forecasts to evaluate regional smoke, photochemical smog, and background pollutant distributions.
  • Source: NASA Global Modeling and Assimilation Office (GMAO) & NASA NCCS OPeNDAP Server.
  • Collection: chm_tavg_1hr_glo_L1440x721_slv (Full 2D Surface Atmospheric Chemistry, Hourly).
  • Target Species: o3, co, no2, hcho, (auto-converted to ppb) and pm25_rh35, pm25oc_rh35 (in μg m-3).
  • Grid Resolution: 0.25° × 0.25° (1440 × 721 global grid), converted and rendered to Web Mercator PNG tiles / GeoTIFF.

2. Main Workflow

1OPeNDAP Subsetting: Calculates time index offsets and spatial grid indices for the North American bounding box (lon: -179° to -13°, lat: 14° to 73°) to query remote OPeNDAP endpoints.
2Matrix Streaming & Parsing: Streams 2D ASCII grid matrices directly over HTTP without downloading multi-gigabyte NetCDF files, minimizing memory overhead.
3Unit Transformation: Converts gaseous species from molar mixing ratios (mol mol-1) to parts per billion (ppb; factor 109), while retaining particulate mass in μg m-3.
4SpatRaster Alignment: Aligns 0.125° half-cell offsets with terra, reprojects to EPSG:3857, and encodes values into 8-bit PNG images with JSON scaling metadata.
5Cloud Sync: Synchronizes generated raster tiles and metadata to Google Cloud Storage (GCS).

4. Technical Implementation

- Remote OPeNDAP Query with Spatial Slicing

Constructs coordinate-indexed OPeNDAP ASCII query strings for on-the-fly server-side spatial sub-setting.

# OPeNDAP Query URL Construction for Spatial Window
query_url <- paste0(
  "https://opendap.nccs.nasa.gov/dods/gmao/geos-cf/v2/ana/", collection, ".ascii?",
  product, "[", time_idx, "][0][", lat_idx_min, ":", lat_idx_max, "][", lon_idx_min, ":", lon_idx_max, "]"
)

# Stream 2D ASCII matrix
raw_lines <- readLines(query_url, warn = FALSE)
val_lines <- grep("^\[\d+\]", raw_lines, value = TRUE)

- Raster Reconstruction & Reprojection

Reconstructs native spatial grids using terra::rast with half-cell centering offsets before reprojecting to Web Mercator.

# Half-cell offset (0.25 / 2 = 0.125) for exact grid boundaries
dres <- 0.25 / 2
i_rast <- terra::rast(
  mat[nrow(mat):1, ],
  extent = terra::ext(actual_lon_min - dres, actual_lon_max + dres, actual_lat_min - dres, actual_lat_max + dres),
  crs = "EPSG:4326"
)

# Reproject to Web Mercator (EPSG:3857) for web tile rendering
i_rast_3857 <- terra::project(i_rast, "EPSG:3857")
