EPA/AirFuse Data Processing

Last Updated: 2026-08-24

Fetches and processes EPA/AirNow-Tech AirFuse (NAQFC Data Fusion) hourly air quality datasets. AirFuse integrates numerical chemical transport model simulations (NOAA NAQFC) with in-situ AirNow monitoring station observations using residual bias correction, producing continuous high-resolution ground-level concentration surfaces for PM2.5 and Ozone across North America.

1. Key Information

  • Purpose: Provide continuous, gap-filled spatial surface fields of fine particulate matter (PM2.5) and surface ozone (O3) by fusing monitoring network data with numerical forecast models.
  • Source: AirNow-Tech & AirNow S3 public buckets (airnow-navigator-layers.s3.us-east-2.amazonaws.com).
  • Products: Fusion_PM25_NAQFC (PM2.5 Fusion in μg m-3) and Fusion_O3_NAQFC_airnow (Ozone Fusion in ppb).
  • Temporal Resolution: Hourly continuous updates (00:00 – 23:00 UTC).
  • Output: Compressed GeoJSON (.geojson.gz) uploaded to Google Cloud Storage (GCS).

2. Main Workflow

1Hourly URL Construction: Generates target S3 endpoints for each date (YYYY/MM/DD) and UTC hour (00–23) for PM2.5 and O3 fusion layers.
2Parallel Ingestion: Downloads multi-hourly GeoJSON payloads concurrently using a multi-core cluster (foreach with doSNOW).
3Vector Validation & Formatting: Parses vector geometries with sf, verifies feature integrity, and formats standard GeoJSON (RFC7946=YES).
4Gzip Compression & GCS Upload: Compresses finalized GeoJSON files into .geojson.gz and uploads them to Google Cloud Storage (GCS).

4. Technical Implementation

- S3 Direct Fetch & Hourly Grid Generation

Constructs dynamic S3 object endpoints for NAQFC data fusion products across all 24 UTC hourly intervals.

# Hourly Grid & Target AWS Endpoint Construction
awsroot <- "https://airnow-navigator-layers.s3.us-east-2.amazonaws.com"

# Example URL pattern for PM2.5 fusion
url <- paste0(
  awsroot, "/fusion/PM25/", i_year, "/", i_month, "/", i_day, "/", i_time,
  "/Fusion_PM25_NAQFC_", i_year, "-", i_month, "-", i_day, "T", i_time, "Z.geojson"
)

# Resilient HTTP GET
temp_geojson <- tempfile(fileext = ".geojson")
res <- httr::GET(url, httr::write_disk(temp_geojson, overwrite = TRUE))

- Parallel Processing & Compression

Spawns parallel workers to validate vector layers, write standard RFC7946 GeoJSON, and gzip-compress files prior to cloud object storage delivery.

# Multi-core execution for 24-hour batch
cl <- makeCluster(cpu_cores)
registerDoSNOW(cl)

foreach(i = 1:nrow(date_list), .packages = c("dplyr", "httr", "sf", "jsonlite")) %dopar% {
  i_output <- sf::st_read(temp_geojson, quiet = TRUE)
  sf::st_write(obj = i_output, dsn = i_file_main_path, driver = "GeoJSON",
               layer_options = c("RFC7946=YES"), delete_dsn = TRUE, quiet = TRUE)
  
  # Gzip compression
  con <- gzfile(i_file_main_path_gzip, "w")
  writeLines(readLines(i_file_main_path), con = con)
  close(con)
  unlink(i_file_main_path)
}
