EPA/AirNow Data Processing

Fetches real-time and historical air quality monitoring data (PM2.5, MDA8 O3, etc.) from AirNow S3 archives and processes it into spatial formats for web visualization.

1. Key Information

  • Purpose: Retrieve daily mean PM2.5 and MDA8 O3 concentrations from the EPA/AirNow monitoring network across the US, Canada, and Mexico.
  • Source: AirNow S3 public buckets (s3-us-west-1.amazonaws.com/files.airnowtech.org).
  • Environment: Designed for Docker and Google Cloud Run.
  • Output: Compressed GeoJSON (.gz) files uploaded to Google Cloud Storage (GCS).

2. Main Workflow

1Authenticate: Connects to Google Cloud Services (GCS) via service account or Cloud Run identity.
2Download: Constructs direct URLs to AirNow S3 buckets and downloads daily pipe-delimited (|) data files.
3Spatial Join: Maps monitoring stations to US states, Canadian provinces, and Mexico boundaries using rnaturalearth.
4Format: Cleans, pivots variables (PM2.5 and O3), assigns AQS codes, and converts to GeoJSON (RFC 7946).
5Upload: Saves compressed (.gz) GeoJSON files to the smokelyze_bucket.

4. Technical Implementation

- S3 Data Retrieval

Constructs direct URLs to AirNow S3 buckets to pull daily raw data packets in a pipe-delimited format.

# Construction of S3 URLs
url_datetime <- paste0(url_year, "/", url_date, "/daily_data_v2.dat")
dataset_url <- paste0("https://s3-us-west-1.amazonaws.com//files.airnowtech.org/airnow/", url_datetime)

# Parsing pipe-delimited data
output_sub <- read.csv(dataset_url, sep = "|", header = F)
colnames(output_sub) <- c("date", "AQS_code", "lat", "lon", "site_name", "var", "value")

- Spatial Join & Boundary Mapping

Using sf, the script intersects monitoring points with political boundaries (States/Provinces) from rnaturalearth to assign geographic context. 

# Convert coordinates to SF points
sf_airnow <- st_as_sf(df_airnow, coords = c("lon", "lat"), crs = 4326)

# Load boundary data
ne_states <- ne_states(country = c("united states of america", "canada", "mexico"), returnclass = "sf")

# Spatial intersection
sf_joined <- st_join(sf_airnow, ne_states[, c("name", "iso_a2")])
