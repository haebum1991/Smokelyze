UW GAM-v2 Prediction Pipeline

The core prediction engine that applies pre-trained Generalized Additive Models (GAM-v2) to new data (2025+), utilizing collected predictor variables from MERRA-2, TROPOMI, and HYSPLIT, with Empirical Distribution Matching (EDM) for bias correction.

1. Key Information

  • Purpose: Predict background MDA8 O3 on smoke days using the pre-trained GAM-v2 architecture (Lee and Jaffe, 2025), then calculate Smoke O3 (SMO) as the residual.
  • Model: Site-specific GAMs stored as pre-trained .rds objects, loaded via mgcv.
  • Pipeline: Merges daily features from MERRA-2 (T2MAX, SRAD, etc.), TROPOMI (NO2, HCHO VCDs), and HYSPLIT (transport distance/height) before running predictions.

2. Main Workflow

1Feature Merging: Combines meteorological (MERRA-2), satellite-derived (TROPOMI), and trajectory (HYSPLIT) metrics into a unified predictor dataframe.
2HMS Overlay: Loads the HMS smoke plume GeoJSON from GCS and performs a spatial overlay to assign a binary smoke flag (HMS = 0/1) to each site.
3Parallel Prediction: Runs site-specific GAM predictions across multiple CPU cores via foreach and doSNOW.
4EDM Bias Correction: Applies Empirical Distribution Matching (EDM) to re-align predicted distributions with historical ground truth, correcting for regression-to-the-mean bias.
5Deployment: Uploads final GeoJSON predictions (including SMO, predicted MDA8 O3, and smoke flags) to GCS for the dashboard.

- Empirical Distribution Matching (EDM)

Applies EDM (Lee and Jaffe, 2024a; 2025) to correct systematic biases in raw GAM outputs by mapping the predicted distribution to match the historical observed distribution of the training period.

# EDM bias correction
gam.bias.correction <- function(y_true, y_pred, y_new, method = "edm") {
  # Step 1: Build ECDFs from training data
  ecdf_y_pred <- ecdf(y_pred)

  # Step 2: Inverse ECDF from observed data
  inverse_ecdf_obs <- approxfun(
    sort(y_true), seq_along(y_true) / length(y_true)
  )

  # Step 3: Map new predictions through the quantile transfer
  prob <- ecdf_y_pred(y_new)
  y_new_corr <- quantile(y_true, probs = prob, type = 7)
  return(y_new_corr)
}
