Smoke Day Identification

1. Definition of a Smoke Day

Identifying the presence of surface-level smoke is the critical first step. A "Smoke Day" is defined as the intersection of overhead smoke plumes detected via satellite and abnormal ground-level PM2.5 concentrations (Lee and Jaffe, 2024a; 2024b; 2025).

Identifying Surface Impacts: Satellite data (HMS) indicates the presence of smoke in the atmospheric column, but not necessarily at breathing level. By cross-referencing HMS with local PM2.5-criteria, we identify meaningful surface impacts that directly affect public health.

2. Identification Logic

The identification algorithm uses a dual-conditional approach. The stringency of the PM2.5 threshold (k-factor) varies depending on the pollutant being analyzed to ensure scientific accuracy.

Smoke Day  =  (HMS == 1)  ∩  (PM2.5  >  PM2.5-criteria)
1
Overhead Smoke (HMS == 1): NOAA Hazard Mapping System (HMS) indicates that a smoke plume polygon is present over the monitor station's coordinates.
2
Daily PM2.5 > PM2.5-criteria: Daily PM2.5 concentration exceeds the local baseline. The stringency level applied depends on the research focus:
  • Smoke O3 Analysis (e.g., UW GAM-v2 dataset): Uses k = 1.0 (Median + 1.0 × MAD) as the standard filter.
  • Smoke PM2.5 Analysis (e.g., UW Smoke PM2.5 dataset): Reports both k = 0.5 and k = 1.0 to capture a broader range of impacts.
# Smoke Day Identification (example R code)
df$smoke_m0p5m <- if_else(df$PM2.5 > df$PM2.5_Crit_m0p5m & df$HMS == 1, 1, 0)
df$smoke_m1p0m <- if_else(df$PM2.5 > df$PM2.5_Crit_m1p0m & df$HMS == 1, 1, 0)

3. Data Output Structure

The systematic identification process aggregates various identifiers into a unified structure suitable for mapping and time-series analysis.

Column Logic / Description
HMS HMS flag: 0 (non-overhead smoke plume) or 1 (overhead smoke plume)
PM2.5 Daily mean PM2.5 concentration in µg/m³
PM2.5_Crit_m0p5m PM2.5-Criteria (Med+0.5MAD): Value in µg/m³
PM2.5_Crit_m1p0m PM2.5-Criteria (Med+1MAD): Value in µg/m³
smoke_m0p5m Smoke Day (Med+0.5MAD): 0 (Non-smoke day) or 1 (smoke day)
smoke_m1p0m Smoke Day (Med+1MAD): 0 (Non-smoke day) or 1 (smoke day)
smoke_PM2.5_m0p5m Smoke PM2.5 (Med+0.5MAD): PM2.5 - PM2.5_Crit_m0p5m (if PM2.5 > PM2.5_Crit_m0p5m, else 0)
smoke_PM2.5_m1p0m Smoke PM2.5 (Med+1MAD): PM2.5 - PM2.5_Crit_m1p0m (if PM2.5 > PM2.5_Crit_m1p0m, else 0)

4. Visualization & Analysis

In the tool dashboard, identified smoke days are highlighted for direct comparison with background periods. This differentiation allows users to isolate the specific impact of wildfire events on local air quality (O3 and PM2.5) while controlling for seasonal "normal" fluctuations.
