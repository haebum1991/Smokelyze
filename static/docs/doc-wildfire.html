Wildfire & Incident Tracking

Daily tracker for new wildfire incidents using official government sources and national news RSS feeds, providing both site-specific and narrative situational awareness.

1. Key Information

  • Purpose: Aggregate current wildfire events and news for the US and Canada.
  • Source 1 (NIFC): WFIGS Incident Locations via the ArcGIS REST API (FeatureServer).
  • Source 2 (News): Google News RSS via tidyRSS with keyword-based queries.
  • Output: Two separate GeoJSON files (News and NIFC) uploaded daily to GCS.

2. Main Workflow

1Daily Polling: Queries the NIFC WFIGS ArcGIS endpoint filtering by FireDiscoveryDateTime for the target date.
2RSS Feed Sync: Scrapes Google News using multiple wildfire-related keywords (e.g., "wildland fire", "wildfire smoke", "prescribed fire").
3Geocoding (News): Maps US state and Canadian province names found in headlines to pre-defined center coordinates for map placement.
4Historical Merge: Loads existing daily GeoJSON from GCS and appends new records, avoiding duplicates.
5Archiving: Saves finalized GeoJSON FeatureCollections to GCS, organized by year.

4. Technical Implementation

- NIFC ArcGIS REST API Query

Directly interfaces with the WFIGS (Wildland Fire Interagency Geospatial Services) ArcGIS REST API to pull real-time fire incident locations for a specific date range.

# ArcGIS REST API Query
base_url <- "https://services3.arcgis.com/T4QMspbfLg3qTGWY/ArcGIS/rest/services/WFIGS_Incident_Locations/FeatureServer/0/query"
where_clause <- sprintf("FireDiscoveryDateTime >= DATE '%s' AND FireDiscoveryDateTime < DATE '%s'",
                         target_date, target_date + 1)
res <- GET(base_url, query = list(
  where = where_clause,
  outFields = "*",
  f = "geojson"
))

- Google News RSS Scraping

Queries Google News using keyword-based RSS feeds and parses results with tidyRSS. Summaries are cleaned of HTML tags and truncated to 300 characters.

# Keyword-based RSS search
NEWS_RSS_URL <- paste0("https://news.google.com/rss/search?q=", URLencode(QUERY))
feed <- tidyRSS::tidyfeed(NEWS_RSS_URL) %>%
  filter(as.Date(item_pub_date) >= q_date)

- State-level Geocoding

News headlines are matched against a built-in lookup table of US states and Canadian provinces to assign approximate geographic coordinates for map visualization.
