S5P/TROPOMI Satellite Retrieval

Retrieves tropospheric vertical column densities (VCD) of NO2 and HCHO from the Sentinel-5P TROPOMI satellite to serve as predictor variables for the GAM-v2 model.

1. Key Information

  • Purpose: Extract tropospheric NO2 and HCHO column densities at AQS station coordinates as GAM-v2 predictor features.
  • Source: S5P-PAL (Product Algorithm Laboratory) Level-3 daily data portal.
  • Products: no2-tropospheric (Tropospheric NO2 VCD) and hcho (HCHO VCD).
  • Resolution: Up to 3.5 × 5.5 km grid cells.

2. Main Workflow

1API Query: Queries the S5P-PAL data portal API for available Level-3 daily product links by year.
2NC Download: Fetches NetCDF files containing daily tropospheric NO2 or HCHO data.
3Unit Conversion: Converts raw satellite data from μmol/m2 into standard scientific units (molec./cm2) using Avogadro's constant.
4Point Extraction: Samples the converted raster values at AQS monitoring station coordinates.
5Temporal Smoothing: Applies a 15-day rolling mean to account for day-over-day satellite observation gaps.

4. Technical Implementation

- S5P-PAL Data Portal API Query

Queries the Sentinel-5P Product Algorithm Laboratory (PAL) for Level-3 daily tropospheric NO2/HCHO data granules, organized by product and year.

# Query PAL API for specific product & year
main_query <- paste0(
  "https://data-portal.s5p-pal.com/api/s5p-l3/",
  product, "/day/", year
)
main_q <- jsonlite::fromJSON(txt = main_query, flatten = TRUE)
link_list <- main_q[main_q$date %in% date_list, c("date", "href")]

- NetCDF Processing & AQS Point Extraction

Opens NetCDF files, selects the appropriate variable based on the product type, removes negative (invalid) values, and extracts raster values at each AQS monitoring station coordinate.

# Variable selection based on product
if (output_var == "no2-tropospheric") var_name <- "tropospheric_NO2_column_number_density"
if (output_var == "hcho") var_name <- "tropospheric_HCHO_column_number_density"

# Open NC and extract the target subdataset
nc_data <- ncdf4::nc_open(file.path(saved_path, file_name))
r_layer <- terra::rast(file.path(saved_path, file_name), var_name)
r_layer <- raster::raster(r_layer)
raster::values(r_layer)[raster::values(r_layer) < 0] <- NA  # Remove negative fill values

# Extract at AQS monitor locations
coordinates(lon_lat_df) <- ~lon+lat
crs(lon_lat_df) <- "+proj=longlat +datum=WGS84"
r_value <- raster::extract(r_layer, lon_lat_df)

# Unit conversion: µmol/m² -> molec./cm²
r_value <- r_value * 6.022e13

- 15-Day Rolling Mean

Loads the past 15 days of extracted data from GCS, splits by AQS site, and applies a centered 15-day rolling mean using data.table::frollmean to smooth day-over-day satellite observation gaps.

# 15-day rolling mean per AQS site
rolling_window <- seq.Date(as.Date(target_date) - 15, as.Date(target_date) - 1, by = "1 day")
output_list <- split(output, output$AQS)

for (ii in seq_along(output_list)) {
  q <- as.data.table(output_list[[ii]])
  q$NO2S5P <- data.table::frollmean(q$NO2S5P_raw, n = 15, na.rm = TRUE, align = "center")
  q$HCHOS5P <- data.table::frollmean(q$HCHOS5P_raw, n = 15, na.rm = TRUE, align = "center")
  output_list[[ii]] <- q[q$date == rolling_date, ]
}
