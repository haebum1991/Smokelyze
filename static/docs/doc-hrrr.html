NOAA/HRRR Model Data Processing

Last Updated: 2026-07-23

Processes High-Resolution Rapid Refresh (HRRR) numerical weather and atmospheric smoke model outputs from NOAA over the Continental United States (CONUS). This pipeline extracts near-surface smoke concentration (8 m above ground) and column-integrated smoke mass density, enabling continuous evaluation of ground-level air quality impacts and total overhead smoke loads.

1. Key Information

  • Purpose: Extract surface smoke concentration and column-integrated smoke density from operational NOAA HRRR simulations for air quality analysis and model comparison.
  • Source: NOAA HRRR Archive on Google Cloud Storage (GCS).
  • Products: MASSDEN:8 m (Near-surface smoke mass concentration in μg m-3) and COLMD:entire (Column-integrated smoke mass density in μg m-2).
  • Resolution: Native 3 km spatial resolution, aggregated to ~6-7 km grid in EPSG:3857 for web performance.
  • Refresh Rate: Hourly operational atmospheric model runs.

2. Main Workflow

1Direct GCS Streaming: Accesses NOAA HRRR GRIB2 files on GCS via GDAL virtual file system (/vsicurl/) without downloading complete datasets to local storage.
2Subdataset Extraction: Uses index (.idx) files to locate and extract targeted subdatasets (MASSDEN:8 m or COLMD:entire) from GRIB2 files.
3Unit Standardization: Converts raw scientific units (kg m-3 for concentration, kg m-2 for column density) into standard air quality units (μg m-3 and μg m-2).
4Spatial Resampling & Projection: Aggregates 3 km grid cells by a factor of 2 (~6-7 km) and reprojects grid from native Lambert Conformal to EPSG:3857 (Web Mercator).
5Web Raster Encoding: Encodes continuous floating-point fields into 8-bit integer PNG rasters and generates companion JSON metadata for web display and value decoding.

4. Technical Implementation

- Direct Streaming via vsicurl

Streams targeted GRIB2 subdatasets directly from NOAA's public GCS bucket using GDAL's /vsicurl/ virtual protocol, avoiding massive GRIB2 downloads.

# Formulate GCS virtual file path for direct streaming
tz_path <- paste0("t", sprintf("%02d", tz_hr), "z")
url_base <- "https://storage.googleapis.com/high-resolution-rapid-refresh"
i_file_name <- paste0("hrrr.", tz_path, ".wrfsfcf00.grib2")
i_full_path <- paste0("/vsicurl/", url_base, "/hrrr.", date_str, "/conus/", i_file_name)

# Read raster stack directly from Cloud Storage
i_rast <- terra::rast(i_full_path)
target_idx <- grep("MASSDEN:8 m", names(i_rast))
i_rast <- i_rast[[target_idx[1]]]

- Unit Conversion Logic

Converts mass density and column-integrated density values from SI units (kg) to microgram (μg) scientific notation.

# Unit conversion helper function
if (product == "COLMD:entire") {
  # Convert kg/m² to µg/m²
  i_rast <- i_rast * 1e9
} else if (product == "MASSDEN:8 m") {
  # Convert kg/m³ to µg/m³
  if (as.Date(date) > as.Date("2021-12-21")) {
    i_rast <- i_rast * 1e9
  }
}

- Spatial Aggregation & Web PNG Normalization

Aggregates native grid resolution, reprojects to EPSG:3857, normalizes floating-point values into 8-bit integers (0-255), and outputs PNG tiles with min/max metadata JSON.

# Aggregate (3 km -> 6-7 km) & Reproject
i_rast <- terra::aggregate(i_rast, fact = 2, fun = "mean", na.rm = TRUE)
i_rast <- terra::project(i_rast, "EPSG:3857", method = "bilinear")

# 8-bit Normalization
i_min <- terra::global(i_rast, fun = "min", na.rm = TRUE)[1, 1]
i_max <- terra::global(i_rast, fun = "max", na.rm = TRUE)[1, 1]

r_encoded <- (i_rast - i_min) / (i_max - i_min) * 255
r_encoded[is.na(r_encoded)] <- 0

# Save 8-bit PNG and JSON Metadata
terra::writeRaster(r_encoded, filename = png_file_path, datatype = "INT1U", filetype = "PNG", NAflag = 0)
write(jsonlite::toJSON(list(min_val = i_min, max_val = i_max, crs_file = "EPSG:3857"), auto_unbox = TRUE), json_file_path)
