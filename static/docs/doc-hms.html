NOAA Hazard Mapping System (HMS) Processing

Fetches and processes NOAA HMS (Hazard Mapping System) smoke plume and fire hotspot data. It downloads raw shapefiles from NOAA NESDIS, unions smoke polygons by density category, computes state-level smoke coverage areas, and converts results into lightweight GeoJSON for web visualization.

1. Key Information

  • Purpose: Track smoke plumes and fire hotspots across North America for smoke day identification and mapping.
  • Source: NOAA NESDIS Office of Satellite and Product Operations — HMS Smoke/Fire shapefile archive.
  • Smoke Categories: Light, Medium, Heavy (density-based classification).
  • Output: GeoJSON for smoke plumes, fire points, and JSON for state-level smoke area statistics (km²).

2. Main Workflow

1Download: Retrieves daily ZIP files containing HMS smoke polygon and fire point shapefiles from NOAA servers.
2Geometry Validation: Transforms shapefiles to WGS84 (EPSG:4326), validates geometries, and removes invalid features.
3Polygon Union: Unions smoke plume polygons by density category (Light, Medium, Heavy) and as a combined total layer.
4Area Calculation: Intersects unified smoke polygons with US state and Canadian province boundaries, then computes coverage area in km².
5Serialization: Converts all results to compressed GeoJSON and uploads to GCS.

4. Technical Implementation

- Shapefile Extraction & Validation

HMS data is distributed as daily ZIP files. The script unzips, loads shapefiles into sf objects, transforms to WGS84, and validates geometries before processing.

# Unzip and load shapefile
unzip(zip_path, exdir = temp_dir)
shp_smoke <- st_read(file.path(temp_dir, shp_name), quiet = TRUE) %>%
  st_transform(crs = 4326)

# Validate and remove invalid geometries
validity <- st_is_valid(shp_smoke, reason = TRUE)
invalid <- which(!str_detect(validity, "Valid"))
if (length(invalid) != 0) shp_smoke <- shp_smoke[-invalid, ]

- Polygon Union by Density

Multiple overlapping smoke plumes are unified based on their density category (Light, Medium, Heavy) to avoid double-counting areas and create clean map layers.

# Union all polygons for combined layer
shp_smoke_uni <- sf::st_union(shp_smoke)

# Separate by density category
shp_smoke_light  <- shp_smoke[shp_smoke$Density == "Light", ] %>% st_union()
shp_smoke_medium <- shp_smoke[shp_smoke$Density == "Medium", ] %>% st_union()
shp_smoke_heavy  <- shp_smoke[shp_smoke$Density == "Heavy", ] %>% st_union()

- Smoke Coverage Area Calculation

Calculates the exact geographic smoke coverage (km²) within each US state and Canadian province by intersecting the unified smoke polygons with administrative boundaries.

# Spatial intersection with states
smoke_intersect <- st_intersection(shp_smoke_union, ne_states)

# Area calculation in km^2
smoke_intersect$area_km2 <- st_area(smoke_intersect) %>%
  set_units("km^2") %>%
  as.numeric()
