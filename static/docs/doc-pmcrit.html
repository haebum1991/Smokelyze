PM2.5-criteria Calculation

1. Overview

The PM2.5-criteria is a site-specific and month-specific threshold used to distinguish background "normal" PM2.5 from smoke-influenced elevated concentrations. This methodology has evolved to improve robustness against outliers and non-normal distributions typical of air quality data.

Methodological Improvement: While Lee and Jaffe (2024a; 2024b) utilized a Mean + Standard Deviation (SD) approach, the Median + Median Absolute Deviation (MAD) method was adopted in Lee and Jaffe (2025) and Jaffe et al. (2026) to better handle extreme values and provide a more reliable baseline.

2. Main Workflow

1
Data Partitioning: Categorizes daily PM2.5 concentrations into "HMS=0" (background, non-overhead smoke) and "HMS=1" (overhead smoke) based on NOAA HMS data.
2
Seasonal Baselining: Aggregates background PM2.5 data (HMS=0) by calendar month using a rolling 5-year window to capture region-specific seasonality.
3
Event Filtering: Excludes non-smoke PM2.5 anomalies, such as Independence Day fireworks (Jul 4–5), to prevent background contamination.
4
Robust Statistics: Calculates the monthly Median and MAD of background PM2.5 for each station (requires >= 10 valid observations).
5
Threshold Synthesis: Computes the PM2.5-criteria = Median + (k × MAD), establishing the site-specific threshold for surface smoke identification.

3. Step-by-Step Implementation

- Data Input & Structure (df_pm25)

The input dataset (df_pm25) merges EPA/AirNow monitoring networks with NOAA HMS smoke plumes.

- Baseline Isolation

We first establish a site-specific background by isolating days where satellite instruments detect non-overhead smoke (HMS=0) and excluding known non-smoke anomalies (fireworks).

# Background filtering logic
df_hms0 <- df_pm25[, c("AQS", "pm25", "HMS", "year", "month", "day")] %>%
  dplyr::filter(HMS == 0) %>%
  dplyr::filter(!(month == 7 & day %in% c(4, 5))) # Fireworks exclusion

- Calculating PM2.5-criteria

For each site and month, the criteria are calculated using the 5-year aggregate distribution to balance stability and relevance.

Example (Rolling Baseline): The criteria for Jan 2025 at Site A is calculated as the Median + 1 × MAD of all "HMS=0" days in Jan across the 2021–2025 period. 
# Monthly robust statistics (Aggregated over 5 years)

year_target <- max(unique(df_hms0$year))
year_from <- year_target - 4

df_hms0 <- df_hms0 %>%
  dplyr::filter(year %in% c((year_from:year_target))) %>%
  dplyr::select(-year, -HMS, -day) %>%
  na.omit()

df_crit <- df_hms0 %>%
  dplyr::group_by(AQS, month) %>%
  dplyr::summarize(
    n_pm_hms0 = n(),
    pm_crit_med = median(pm25, na.rm = TRUE),
    pm_crit_mad = mad(pm25, na.rm = TRUE, constant = 1.4826) # R default
  )
df_crit$year <- year_target

# Criteria calculation (k = 1.0, or 0.5 if you want)
k <- 1
df_crit$pm_crit <- df_crit$pm_crit_med + (k * df_crit$pm_crit_mad)

- Stringency Levels (k-factor)

k Factor Classification Scientific Use
0.5 Low Stringency Capturing subtle/diluted smoke influence (Jaffe et al., 2026)
1.0 Standard Optimized balance for national studies (Lee and Jaffe, 2025; Jaffe et al., 2026)
1.5 High Stringency Conservative identification of heavy smoke events

- State-level Fallback (Imputation)

To maintain spatial continuity across the monitoring network, a State-level Fallback mechanism is applied. Stations failing the minimum data sufficiency check (n < 10 valid HMS=0 observations) have their local thresholds replaced by the state-wide average criteria for the corresponding month. This imputation ensures that even sites with sparse background data can effectively isolate smoke events using regional baseline context.

4. Web App Integration

Following the methodology inspired by Lee and Jaffe (2025) and Jaffe et al. (2026), which used a fixed 6-year period (2019-2024), this application recalibrates these 5-year rolling criteria annually to provide the most current context for smoke identification in the dynamic US wildfire environment.
