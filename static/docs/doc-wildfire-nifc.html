NIFC Incident Locations & Perimeters

Last Updated: 2026-08-24

6-hourly tracker for new wildfire incidents and active fire perimeter boundaries using official government sources, providing site-specific situational awareness across the United States.

1. Key Information

  • Purpose: Aggregate current wildfire point locations and active burn perimeters for the US.
  • Source (NIFC): WFIGS (Wildland Fire Interagency Geospatial Services) Incident Locations & Interagency Perimeters via the ArcGIS REST API (FeatureServer).
  • Output: GeoJSON files (NIFC Incidents & Perimeters) uploaded daily to GCS.

2. Main Workflow

1Daily Polling: Queries NIFC WFIGS ArcGIS endpoints for both point incidents and polygon perimeters for the target date.
2Data Extraction: Retrieves key attributes such as Incident Name, Discovery Acres, Fire Cause, and geometry coordinates/polygons.
3Archiving: Saves finalized GeoJSON FeatureCollections to GCS organized by year for interactive map visualization.

4. Technical Implementation

- NIFC ArcGIS REST API Query

Directly interfaces with the WFIGS ArcGIS REST FeatureServer endpoints to query real-time wildfire data for a target date. Below is a representative example querying incident point locations (a similar REST query structure is used for active fire perimeter boundaries).

# Example: WFIGS Incident Locations Query
base_url <- "https://services3.arcgis.com/T4QMspbfLg3qTGWY/ArcGIS/rest/services/WFIGS_Incident_Locations/FeatureServer/0/query"
where_clause <- sprintf("FireDiscoveryDateTime >= DATE '%s' AND FireDiscoveryDateTime < DATE '%s'",
                         target_date, target_date + 1)
res <- GET(base_url, query = list(
  where = where_clause,
  outFields = "IncidentName, DiscoveryAcres, FireDiscoveryDateTime, InitialLatitude, InitialLongitude",
  f = "geojson"
))
