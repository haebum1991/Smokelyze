NIFC Incident Location Tracking

Last Updated: 2026-07-24

6-hourly tracker for new wildfire incidents using official government sources, providing site-specific situational awareness.

1. Key Information

  • Purpose: Aggregate current wildfire events for the US.
  • Source (NIFC): WFIGS Incident Locations via the ArcGIS REST API (FeatureServer).
  • Output: GeoJSON files (NIFC) uploaded daily to GCS.

2. Main Workflow

1Daily Polling: Queries the NIFC WFIGS ArcGIS endpoint filtering by FireDiscoveryDateTime for the target date.
2Data Extraction: Retrieves key fields such as Incident Name, Discovery Acres, and Incident Type.
3Archiving: Saves finalized GeoJSON FeatureCollections to GCS, organized by year.

4. Technical Implementation

- NIFC ArcGIS REST API Query

Directly interfaces with the WFIGS (Wildland Fire Interagency Geospatial Services) ArcGIS REST API to pull real-time fire incident locations for a specific date range.

# ArcGIS REST API Query
base_url <- "https://services3.arcgis.com/T4QMspbfLg3qTGWY/ArcGIS/rest/services/WFIGS_Incident_Locations/FeatureServer/0/query"
where_clause <- sprintf("FireDiscoveryDateTime >= DATE '%s' AND FireDiscoveryDateTime < DATE '%s'",
                         target_date, target_date + 1)
res <- GET(base_url, query = list(
  where = where_clause,
  outFields = "IncidentName, DiscoveryAcres, FireDiscoveryDateTime, InitialLatitude, InitialLongitude",
  f = "geojson"
))
