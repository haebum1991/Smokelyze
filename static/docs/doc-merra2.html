NASA MERRA-2 Processing

Downloads and processes NASA Modern-Era Retrospective analysis for Research and Applications, Version 2 (MERRA-2) data to provide meteorological predictor variables for the GAM-v2 model.

1. Key Information

  • Purpose: Extract meteorological variables (T2MAX, SRAD, QV2M, U10M, V10M, PBLH) at AQS monitoring station coordinates.
  • Source: NASA GES DISC EarthData portal (GOLDSMR4 archive).
  • Products: M2T1NXSLV (hourly surface), M2T1NXRAD (hourly radiation), M2STATMNXSLV (monthly statistics).
  • Target: Input predictor features for the GAM-v2 Smoke O3 model.

2. Main Workflow

1Token Auth: Generates an EarthData bearer token via .netrc configuration for secure NetCDF downloads.
2NC Download: Fetches hourly and daily multi-dimensional NetCDF4 files (M2T1NXSLV, M2T1NXRAD, etc.) using curl.
3Point Extraction: Samples raster grid values at exact monitoring station coordinates using raster::extract.
4Statistics: Computes daily aggregates: max temperature (T2MAX), mean solar radiation (SRAD), and mean wind components (U10M, V10M).
5Integration: Formats extracted data into GeoJSON for direct use in GAM prediction or model training.

4. Technical Implementation

- EarthData Authentication

Authenticates with NASA URS using .netrc credentials to retrieve a temporary bearer token for accessing MERRA-2 data layers.

# Find or create EarthData token
res <- GET(
  "https://urs.earthdata.nasa.gov/api/users/find_or_create_token",
  authenticate(user, pass)
)
token <- content(res)$access_token

- Remote NetCDF Download

Downloads hourly/daily meteorological NetCDF files (temperature, radiation, wind, humidity) using the secured bearer token. The download list is dynamically scraped from the GOLDSMR4 archive catalog.

# Download with Bearer Auth via curl
curl::curl_download(
  url = dataset_url,
  destfile = output_path,
  handle = handle
)

- Grid-to-Point Extraction

Extracts meteorological variables from 2D NetCDF raster grids at specific AQS monitoring station locations.

# Raster stacking and point extraction
nc_raster <- raster::stack(local_path, varname = "T2MMAX")
station_points <- sp::SpatialPoints(cbind(df_aqs$lon, df_aqs$lat), crs_wgs84)
extracted_vals <- raster::extract(nc_raster, station_points)
