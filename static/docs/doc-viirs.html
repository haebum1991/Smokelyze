NOAA/VIIRS Satellite Retrieval

Last Updated: 2026-07-23

Retrieves daily corrected reflectance true-color satellite imagery from the Visible Infrared Imaging Radiometer Suite (VIIRS) instrument aboard the NOAA-21 satellite via NASA Worldview's Global Imagery Browse Services (GIBS). VIIRS is a polar-orbiting sensor that captures high-resolution daytime imagery over North America once per day, offering detailed visual inspection of smoke plume structure, surface fire footprints, and regional clarity.

1. Key Information

  • Purpose: Provide daily high-spatial-resolution true-color satellite imagery for visually inspecting smoke plume boundaries, cloud cover, and surface terrain impacts.
  • Source: NASA Worldview GIBS (Global Imagery Browse Services) API.
  • Products: VIIRS_NOAA21_CorrectedReflectance_TrueColor (NOAA-21 VIIRS Corrected Reflectance True Color).
  • Resolution: Native ~250–750 m spatial resolution, processed and rendered to ~4 km Web Mercator (EPSG:3857) resolution for web display optimization.
  • Refresh Rate: Daily polar-orbiting swath coverage across North America (CONUS, Canada, and Alaska).

2. Main Workflow

1API Query Construction: Constructs NASA GIBS WMS request URLs specifying the layer name, target observation date, and coordinate bounding box.
2Coordinate Transformation: Transforms geographic longitude/latitude bounds (lon: -179° to -13°, lat: 14° to 73°) into Web Mercator (EPSG:3857) meters to eliminate spatial warping.
3Imagery Fetching: Requests composite daily true-color PNG frames directly from NASA GIBS high-performance endpoints.
4WebP Compression: Converts downloaded raw PNG images into optimized, compressed 8-bit WebP images (quality factor 70) for rapid client loading.
5Metadata Export: Generates accompanying JSON metadata files storing image dimensions, layer metadata, and bounding box extents in EPSG:3857.

4. Technical Implementation

- Geographic to Web Mercator Bounding Box Conversion

Converts geographic degree coordinates into Web Mercator linear meter extents to request native EPSG:3857 tiles directly from NASA GIBS.

# Helper function: lon/lat degrees to EPSG:3857 Web Mercator meters
deg_to_merc <- function(lon, lat) {
  r <- 6378137
  x <- r * lon * pi / 180
  y <- r * log(tan(pi / 4 + lat * pi / 360))
  return(c(x, y))
}

# Transform North American bounding box
min_xy <- deg_to_merc(-179, 14)  # lon_min, lat_min
max_xy <- deg_to_merc(-13, 73)   # lon_max, lat_max

# Calculate dimensions for target 4 km resolution
width  <- round((max_xy[1] - min_xy[1]) / 4000)
height <- round((max_xy[2] - min_xy[2]) / 4000)

- NASA GIBS WMS Fetching & WebP Tile Encoding

Issues a WMS GetMap request to NASA GIBS, downloads the raw true-color PNG frame, and re-encodes the raster into a compressed WebP tile alongside metadata JSON.

# Construct NASA GIBS WMS query URL (EPSG:3857)
gibs_url <- sprintf(
  "https://gibs.earthdata.nasa.gov/wms/epsg3857/best/wms.cgi?SERVICE=WMS&REQUEST=GetMap&LAYERS=%s&TIME=%s&BBOX=%f,%f,%f,%f&WIDTH=%d&HEIGHT=%d&FORMAT=image/png",
  "VIIRS_NOAA21_CorrectedReflectance_TrueColor", target_date_str,
  min_xy[1], min_xy[2], max_xy[1], max_xy[2], width, height
)

# Fetch image and convert to compressed WebP
res <- httr::GET(gibs_url, httr::write_disk(tmp_png_path, overwrite = TRUE))
img_data <- png::readPNG(tmp_png_path)
webp::write_webp(img_data, target_webp_path, quality = 70)

# Export JSON metadata
meta_info <- list(
  id = "VIIRS_NOAA21_CorrectedReflectance_TrueColor",
  datetime = target_date_str,
  extent_file = c(min_xy[1], max_xy[1], min_xy[2], max_xy[2]),
  crs_file = "EPSG:3857"
)
write(jsonlite::toJSON(meta_info, auto_unbox = TRUE), json_meta_path)
