Generalized Additive Model (GAM) for Smoke O3 (SMO) Calculation

1. Scientific Objective

The core analysis utilizes Generalized Additive Models (GAM) to precisely quantify the portion of ground-level MDA8 O3 (and PM2.5) directly attributable to wildfire smoke. Developed and validated across multiple studies (Lee and Jaffe, 2024a; 2024b; 2025), this methodology identifies Smoke O3 (SMO) by isolating the wildfire signal from meteorological and seasonal drivers.

Smoke O3 (SMO): The O3 enhancement attributed to wildfire smoke, calculated as the difference between the observed concentration and the GAM-predicted background:
SMO = Residual = Obs MDA8 O3 - Pred MDA8 O3

2. Analysis Workflow

1
Data Partitioning: Using HMS satellite flags and PM2.5-criteria, the dataset is split into Non-smoke days (Background) and Smoke days (Event).
2
Background Training: The GAM is trained exclusively on Non-smoke day data to establish the relationship between meteorology and background air quality.
3
Counterfactual Prediction: Meteorological data from Smoke days is inputted into the trained background model to predict what the concentration would have been without wildfire influence (Predicted MDA8 O3).
4
SMO Derivation: The SMO is calculated as the residual (Observed - Predicted) on smoke days, representing the quantified wildfire contribution.

3. Technical Framework (e.g., GAM-v2 Implementation)

The quantification process leverages site-specific GAMs. To illustrate this methodology using the GAM-v2 framework (Lee and Jaffe, 2025) as an example, the model utilizes 14 independent predictors and interaction smooth terms to capture complex atmospheric nonlinearities.

  • Meteorological Drivers (MERRA-2): MAX-Temperature, Specific Humidity, and Solar Radiation.
  • Wind Vector Tensor Smooths: Tensor product terms `te(U10M, V10M)` account for the combined influence of wind speed and direction on pollution stagnation and transport.
  • Synergistic Photochemical Interactions: Interaction smooths `ti(T2MAX, SRAD)` capture the nonlinear relationship between temperature and solar radiation, which is critical for O3 formation.
  • Transport & Precursor Tracers: Includes HYSPLIT backward trajectory statistics (transport distance/height) and satellite-derived tracers (TROPOMI NO2 and HCHO VCDs).
# Representative R implementation (mgcv framework)
df_train <- df[df$smoke == 0, ] # Training data (non-smoke days)
df_smoke <- df[df$smoke == 1, ] # Smoke days data
gam_model <- gam(MDA8O3 ~ s(T2MAX) + s(RH2M) + s(SRAD) + 
                 s(NO2VCD) + s(HCHOVCD) +
                 te(U10M, V10M) +      # Wind field interaction
                 ti(T2MAX, SRAD) +     # Weather synergy
                 ..., 
                 data = df_train) # Trained on HMS=0 & PM2.5 < criteria (i.e., non-smoke days)

# Predict background O3 on smoke days
pred_MDA8O3 <- predict(gam_model, newdata = df_smoke, type = "response")

# Calculate Smoke O3 (SMO)
df_smoke$SMO <- df_smoke$MDA8O3 - pred_MDA8O3

4. Empirical Distribution Matching (EDM)

To address the model's tendency to underestimate extreme values (regression to the mean), Empirical Distribution Matching (EDM) is applied. EDM maps the predicted distribution to match the historical observed distribution of the background period.

YEDM = QTrobs ( FTrpred ( Ypred ) )

Using EDM (Lee and Jaffe, 2024a; 2025) ensures that the predicted background is statistically consistent with observations, leading to a more robust isolation of SMO.
