NOAA HYSPLIT Backward Trajectory

Runs the HYSPLIT (Hybrid Single-Particle Lagrangian Integrated Trajectory) model to calculate backward trajectories at AQS monitoring stations, deriving transport distance and height metrics as predictor features for the GAM-v2 model.

1. Key Information

  • Purpose: Compute 12-hour backward trajectory statistics (transport distance, height, direction) for use as GAM-v2 predictor variables.
  • Meteorology: Uses NAM12 Met. data.
  • Heights: Trajectories initiated at 500m above ground level.
  • Output: Statistical summaries (Haversine distance, bearing, transport speed) for each site and date.

2. Main Workflow

1Met-Data Sync: Downloads required NAM12 meteorological files from ARL/NOAA servers.
2Execution: Spawns HYSPLIT processes (hyts_std) for each AQS monitor at multiple receptor heights.
3Distance Calculation: Computes Haversine great-circle distance between the receptor and the terminal trajectory point.
4Bearing Analysis: Calculates bearing (directional sector) and transport speed along each trajectory path.
5Archiving: Aggregates results and uploads as GeoJSON to GCS for downstream integration.

- Transport Distance & Bearing

Calculates the great-circle transport distance and bearing using the Haversine formula between the receptor site and the terminal trajectory point.

# Haversine distance calculation
dist_haversine <- function(p1, p2, r = 6378137) {
  toRad <- pi / 180
  p1 <- matrix(p1) * toRad
  p2 <- matrix(p2) * toRad
  dLat <- p2[, 2] - p1[, 2]
  dLon <- p2[, 1] - p1[, 1]
  a <- sin(dLat/2)^2 + cos(p1[,2]) * cos(p2[,2]) * sin(dLon/2)^2
  return(r * (2 * atan2(sqrt(a), sqrt(1 - a)))) # Result in meters
}
