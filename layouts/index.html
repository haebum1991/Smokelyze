Smokelyze

Advanced Spatiotemporal Analytics for Wildfire Smoke & Air Quality

Mission & Purpose

Smokelyze (formerly PMO3smokeTool) was created to precisely analyze the impact of wildfire smoke on air quality across the United States, specifically focusing on health-hazardous concentrations of Ozone (O3) and Fine Particulate Matter (PM2.5) using data-driven insights.

To disentangle the complex interplay between meteorological factors and wildfire impact, we implemented the Generalized Additive Model (GAM) algorithm.

We hope this tool will be useful for state agencies and others in understanding the factors that control O3 production.

Data Pipeline

R code Modular Docker Google Cloud Run Google Cloud Storage

Smokelyze operates on a highly modularized, cloud-native architecture. Each stage of the data lifecycle—from ingestion to advanced statistical modeling—is encapsulated in separate Docker containers, ensuring maximum scalability and reliability.


Multi-Source Acquisition: Automated tasks fetch real-time data from AirNow stations, satellite-detected HMS smoke polygons, and integrated wildfire incident news.
Modeling & Prediction: Periodic R scripts automatically collect MERRA-2, TROPOMI, and HYSPLIT data via Docker to run trained GAM models for future smoke impact analysis.
Automated Delivery: Processed datasets are compressed and deployed to Google Cloud Storage (GCS) buckets, ready for instant retrieval by the Map rendering engine.
