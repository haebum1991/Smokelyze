Smokelyze

[Smokelyze], formerly known as [PMO3smokeTool], is a comprehensive analytical platform for wildfire smoke impact assessment.

https://smokelyze.netlify.app/map/ (JavaScript version)
https://westar.shinyapps.io/PMO3smokeTool/ (R shiny version)

Purpose of tool

The purpose of this app is to demonstrate the application of a Generalized Additive Model (GAM) for predicting MDA8 O3 using meteorological data under both smoke and non-smoke conditions. In this app, a GAM is derived using the "mgcv" package in R. We hope this tool will be useful for state agencies and others in understanding the factors that control O3 production.

Example page in the Smokelyze map

The GAM is a statistical or machine learning framework that provides interpretability by applying smoothing functions to individual variables. Notably, GAMs can incorporate linear, nonlinear, and categorical predictors, providing flexibility for modeling complex relationships (Wood, 2017). In particular, such statistical/machine learning models can provide an efficient tool for analyzing air quality, especially in relation to wildfire smoke. For example, O3 can be used as the response variable, modeled using meteorological data, satellite-derived measurements, and/or backward air trajectories (Lee and Jaffe, 2024). This study demonstrated the importance of wildfire smoke as contributors to exceedances of the health-based national air quality standards for PM2.5 and O3.

If you want to see the results from our studies, which have been published in peer-reviewed journals or are soon to undergo peer review, please go to the [Map] tab. We also provide various research results on PM2.5 and O3 smoke in this tab. You can plot and download results in a variety of formats. Also, if you want to download full dataset for those studies, please go to [Resources] > [Data]tab.
